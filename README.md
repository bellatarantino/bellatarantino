## Current Projects 

### Automated Worksheet Reader
A Python pipeline that reads scanned paper worksheets and outputs structured data. It aligns each page using printed ArUco markers, decodes a printed binary session code with check bits, and reads student and teacher bubble responses with OpenCV, flagging uncertain marks for review. Designed so teachers keep pen-and-paper practice without manual data entry.

### Lesson Engagement Tracking
A study of about 500 high school English learners across two schools, using data collected through Snap & Grade. It examines how perceived difficulty, focus, and activity type relate to performance on practiced skills and on transfer tasks, and whether students can accurately assess their own work. Findings are shared through a dashboard for teachers.
