### Automated Worksheet Reader

A Python pipeline that turns scanned paper worksheets into structured data to maintain pen-and-paper practice **without manual data entry**.

- Aligns pages with printed ArUco markers
- Decodes a binary session code with check bits
- Reads student and teacher bubbles, flagging uncertain marks 

This tool will be used for the study of my own students.

### Lesson Engagement Tracking

A study of **~500 high school English learners** across two schools, using data collected through the automated worksheet reader. 

- How difficulty, focus, and activity type relate to performance
- Practiced skills vs. transfer tasks
- Can students accurately assess their own work?

Findings will be shared with my JET Program supervisors to improve learning methods and track student progress.
